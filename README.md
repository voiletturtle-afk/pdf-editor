# PDF Toolkit

A free, offline-first PDF toolkit with **Thaana / Dhivehi OCR** support.

Features:
- Convert PDF to Images
- Compress PDF
- Merge & Split PDFs
- Rotate Pages
- PDF Info
- **PDF to Text (OCR)** with full Dhivehi (ދިވެހި) support using Tesseract.js

All processing happens in your browser. No data is uploaded.
